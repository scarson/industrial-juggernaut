## Decisions made this session (rationale — these are NOT re-derivable from code)

Recorded in the plan's **Deviations** + **Discoveries** sections; summarized here so a fresh agent sees them without mining:

1. **Unknown-throw policy (A3.2):** unrecognized throws inside command handlers **rethrow** — they never map to a wire error. `MALFORMED` is reserved for transport-layer malformed traffic (per the `WIRE_ERROR_CODES` catalog grouping). Engine/reducer bugs stay loud; the DO discard-and-restart model handles them. **Sam did not veto.**
2. **Three-layer agent-seat auth (Sam-approved):** (1) B2 mints seat tokens for HUMAN seats only; (2) B6.2 refuses to bind a socket to an agent seat (agent seats have `authorizedDigest === null`); (3) the A5 reducer envelope rejects mutating commands from agent-kind seats. All three shipped.
3. **Mid-setup gameOver resolved at the REDUCER layer (not a B3 host patch):** `commitEntries` detects a setup placement that clinches a victory and emits `gameOver`+`terminal` itself. The originally-planned B3 host special-case was adversarially rejected (would split emission across layers; a client-local sandbox would miss it). **B3 needs no terminal-after-drive special case.**
4. **`MALFORMED` for no-base-at-target is correct** (not a resync): a stale view implies a stale `expectedLogIndex`, and STALE_INDEX fires before the target lookup. Reachability argument is a code comment.
5. **`seatClaimed` broadcasts on the claim transition (Sam-directed):** the protocol has NO refresh cycle (resyncs only fire on connect/STALE_INDEX/explicit request), so without a broadcast an idle lobby client never sees a seat fill. Gated on the `claimed` false→true transition.
6. **No CI split (B8):** a real CI log proved the workerd pool RUNS under bun in the required `check` job — host tests have been gated by `check` since B2. So `check` keeps `bun run test` (node+host) and only gains the `--check` guard step. A separate `host-tests` job would have added a branch-protection gap (not in dev's required set). Strictly better.
7. **`head_sampling_rate: 1` stays in production** (Sam + I decided): keep full logs at hobby scale; the reviewer's "drop it" was generic boilerplate. Cost is negligible until sustained thousands-of-req/min.
8. **WIRE-SHAPE-1 two-layer fix (B6):** the reducer trusts the `ClientCommand` shape, so the wire boundary must full-shape-validate. Layer 1 = `parseClientCommand` (`src/host/parse-command.ts`); Layer 2 = a try/catch backstop around the pre-persist `applyCommand` call. Both route to MALFORMED + the abuse budget.
