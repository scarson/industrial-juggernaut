- **`src/agent/random.ts`** — uniformly-random skill floor.

- **Phase 2** (`src/engine/control.ts`): type-aware control radius (forge/watchtower/outpost).
- **Phase 3** (`src/engine/build.ts`, `src/engine/apply.ts`): per-type build cost; `buildBudgetForType`; `Action.build.pieces[*].baseType?`.

- **Phase 5** (`src/engine/legal.ts`): `legalActions` enumerates subtypes when flag on.

All flag-off paths are bit-for-bit identical to pre-change behavior.
